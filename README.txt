SABRINA FRITZSCHE WORDPRESS THEME
Version 1.1.0

INSTALLATION
1. In WordPress open Design > Themes > Add new > Upload theme.
2. Select sabrina-fritzsche-theme.zip and click Install now.
3. Activate the theme.
4. The theme creates Home and Between Signals pages and sets them as front page and posts page.

EDITING
- Essays: Posts > Add new.
- The update restores the full Between Signals archive and individual essay layout. The first essay is created once when the WordPress admin is opened after activation.
- Contact links: Design > Customizer > Links & contact.
- Legal pages: create pages with the slugs impressum and datenschutz.
- Featured images can be added to every essay.

LANGUAGES
The landing page includes German and English copy and remembers the visitor's language choice. Blog posts are standard WordPress posts. For fully separate German and English post archives, install a multilingual plugin such as Polylang after the base site is working.

NEWSLETTER
Until a newsletter provider URL is entered under Links & contact, the call to action opens an email to hello@sabrinafritzsche.com.

SUPPORT
